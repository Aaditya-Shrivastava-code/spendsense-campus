About this project

SpendSense is a student-built expense tracking prototype for FoCP (CSE-1003). It uses HTML, CSS and JavaScript. Your data is stored locally in this browser using LocalStorage.

Privacy note: expenses are not sent to a server and will not automatically sync across different devices or browsers.
